[Trolling mod] Makes **your player appear as a creature** or as **almost any other game prefab**: an
object, a building piece, a ship, etc.

# Installation

1. Copy `Disguise.dll` into `BepInEx\plugins\`.
2. **Requirement:** [Jotunn](https://valheim.thunderstore.io/package/ValheimModding/Jotunn/) is
   required.

Installing the DLL on a dedicated server is **optional but recommended**: it adds automatic observer
refresh and save protection.

Other players do not need to install the mod.

# Configuration

**Configuration File:** `BepInEx\config\orax.Disguise.cfg`

The **Disguise window** can be toggled via `GuiKey` (configurable but not set by default) or by
clicking the new **Disguise** entry in the main menu.

# Console commands (F5)

Type `disguise` or `disguise help` in the console.

# Other mods

This mod does not allow you to play as a creature/mob. If you wish to do that, you should try
**PlayAsMob** by Ten Zly — [Nexus Mods](https://www.nexusmods.com/valheim/mods/3887) |
[Thunderstore](https://thunderstore.io/c/valheim/p/TenZly/PlayAsMob/).
